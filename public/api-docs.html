API Documentation

Complete reference for the Health Information Exchange System REST API. All endpoints require authentication unless otherwise noted.

Base URL: http://localhost:5000/api

Authentication

POST /auth/register

Register a new user account.

Request Body:
{
    "name": "John Doe",
    "email": "john@example.com",
    "password": "password123",
    "role": "user"  // Optional: "user", "provider", or "admin"
}
Response:
{
    "success": true,
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "user": {
        "id": 1,
        "name": "John Doe",
        "email": "john@example.com",
        "role": "user"
    }
}
POST /auth/login

Login and receive JWT token.

Request Body:
{
    "email": "john@example.com",
    "password": "password123"
}
Response:
{
    "success": true,
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
}
GET /auth/me

Get current authenticated user information.

Headers:
Authorization: Bearer <token>

Patients

GET /patients

Retrieve all patients.

GET /patients/:id

Retrieve a specific patient by ID.

POST /patients

Create a new patient record.

Request Body:
{
    "firstName": "Jane",
    "lastName": "Smith",
    "dateOfBirth": "1990-05-15",
    "gender": "Female",
    "email": "jane@example.com",
    "contactNumber": "555-0123",
    "address": "123 Main St",
    "medicalHistory": ["Diabetes", "Hypertension"]
}
PUT /patients/:id

Update a patient record.

DELETE /patients/:id

Delete a patient record.

GET /patients/search?q=query

Search patients by name or email.

Appointments

GET /appointments

Retrieve all appointments.

POST /appointments

Create a new appointment.

Request Body:
{
    "patient": 1,
    "doctor": 2,
    "date": "2024-01-15T10:00:00Z",
    "reason": "Annual checkup"
}
GET /appointments/patient/:patientId

Get all appointments for a specific patient.

GET /appointments/doctor/:doctorId

Get all appointments for a specific doctor.

Medical Records

GET /medical-records

Retrieve all medical records.

GET /medical-records/patient/:patientId

Get all medical records for a specific patient.

POST /medical-records

Create a new medical record.

Request Body:
{
    "patient": 1,
    "visitDate": "2024-01-15T10:00:00Z",
    "diagnosis": [
        {"code": "I10", "description": "Essential hypertension"}
    ],
    "medications": [
        {"name": "Lisinopril", "dosage": "10mg", "frequency": "Once daily"}
    ],
    "vitalSigns": {
        "bloodPressure": "120/80",
        "heartRate": 72,
        "temperature": 98.6
    },
    "notes": "Patient is responding well to treatment."
}

Users

GET /users

Retrieve all users (Admin only).

GET /users/providers

Get all healthcare providers.

PUT /users/:id

Update user information.
