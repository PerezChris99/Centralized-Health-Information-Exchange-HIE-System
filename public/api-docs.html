Authentication

POST /api/auth/register

Register a new user

Request Body:

{
    "username": "doctor1",
    "password": "password123",
    "role": "doctor"
}

Response:

{
    "token": "jwt_token_here"
}

POST /api/auth/login

Login a user

Request Body:

{
    "username": "doctor1",
    "password": "password123"
}

Response:

{
    "token": "jwt_token_here"
}

Patient Endpoints

GET /api/patients

Get all patients

Headers:

Authorization: Bearer jwt_token_here

Response:

[
    {
        "_id": "60f1b5b5e6c8a32a4c9b3f1c",
        "name": "John Doe",
        "age": 45,
        "gender": "male",
        "contactInfo": "john.doe@example.com",
        "medicalHistory": ["Hypertension", "Diabetes"]
    }
]

POST /api/patients

Create a new patient

Headers:

Authorization: Bearer jwt_token_here

Request Body:

{
    "name": "Jane Smith",
    "age": 35,
    "gender": "female",
    "contactInfo": "jane.smith@example.com",
    "medicalHistory": ["Asthma"]
}

Response:

{
    "_id": "60f1b5b5e6c8a32a4c9b3f1d",
    "name": "Jane Smith",
    "age": 35,
    "gender": "female",
    "contactInfo": "jane.smith@example.com",
    "medicalHistory": ["Asthma"]
}
